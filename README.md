### Daniel Nemet

I research how humans and AI systems come to trust each other, and I build the instruments that measure it.

Head of Product at [Nym Technologies](https://nym.com) (privacy infrastructure). PhD researcher in digital epistemology at ELTE Budapest: *Trust as a Context Protocol*.

**Here:**
- [loci](https://github.com/huximaxi/loci): open-source, local-first knowledge system. Memory without a cloud; context that compounds across AI conversations; no telemetry.
- [the Scaffold](https://loci.garden/scaffold.html): a live evaluation board for the AI-memory field. One discipline: a benchmark number with no harness is a claim, not a fact.
- [docs.loci.garden](https://docs.loci.garden): the guidebook.

Everything local-first, everything inspectable.
